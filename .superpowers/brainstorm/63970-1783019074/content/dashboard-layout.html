Admin Dashboard Layout

How should the property management interface be organized?

A

Single Page with Tabs

One URL (/admin) with tabbed sections: Properties, Photos, Settings. Matches existing stats page pattern. Simpler routing.

B

Sidebar Navigation

Traditional admin layout with persistent sidebar. Separate pages: /admin/properties, /admin/photos, /admin/stats. More scalable.

C

Dashboard Overview + Modals

Card-based overview at /admin showing quick stats and property count. Click cards to open modal editors. Modern, task-focused.
