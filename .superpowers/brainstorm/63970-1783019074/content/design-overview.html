Database Schema

properties

  • id, name, location, price
  • status (available | sold | rented)
  • showInShowcase (boolean) — featured in carousel
  • displayOrder — order in showcase

property_photos

  • id, propertyId (FK), url, alt
  • displayOrder — order within property gallery

hero_photos

  • id, url, alt, position (1, 2, or 3)
  • Exactly 3 photos for the stacked cards

Tabs Breakdown

📋 Properties Tab

List all properties with status badges. Click to expand/edit. Inline photo upload (drag & drop to Vercel Blob). Toggle "Show in Showcase" per property.

🖼️ Hero Tab

Upload/manage exactly 3 hero photos. Positions 1, 2, 3 map to front, middle, back cards in the stacked Hero animation.

📊 Stats Tab

Existing stats editor — migrate from /admin/stats into this tab.
