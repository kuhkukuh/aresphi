# Spec: F-001 Project Setup & Infrastructure

**Feature ID:** F-001  
**Priority Score:** 40  
**Estimated Time:** 1.25 hours with AI

---

## Summary

Initialize Next.js 14+ project with TypeScript, Tailwind CSS, Drizzle ORM, Neon PostgreSQL, Clean Architecture structure, and base environment configuration.

---

## Acceptance Criteria

| ID | Given | When | Then |
|----|-------|------|------|
| AC-001 | Developer runs npm install | All dependencies are installed | No errors and package.json contains Next.js 14+, TypeScript, Tailwind CSS, Drizzle ORM |
| AC-002 | Project structure is created | Developer navigates to src/ directory | Clean Architecture folders exist: domain/, application/, infrastructure/, presentation/ |
| AC-003 | Tailwind CSS is configured | Developer adds a className with Tailwind utility | Styles are applied correctly |
| AC-004 | Drizzle ORM is configured | Database connection is attempted | Connection to Neon PostgreSQL succeeds |
| AC-005 | TypeScript strict mode is enabled | Developer runs npm run build | No TypeScript errors with strict mode |
| AC-006 | Environment variables are documented | Developer opens .env.example | All required env vars are listed with descriptions |
| AC-007 | App Router is configured | Developer starts dev server | Application loads at localhost:3000 with App Router structure |

---

## Scope

### In Scope
- Next.js 14+ App Router setup
- TypeScript configuration with strict mode
- Tailwind CSS with custom theme (orange brand color)
- Drizzle ORM setup
- Neon PostgreSQL connection
- Clean Architecture folder structure
- Environment variables setup
- ESLint and Prettier configuration
- Git ignore configuration

### Out of Scope
- Database schema definitions
- UI components
- API routes
- Authentication
- Deployment configuration

## Harness

### Setup Commands
```bash
npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir --import-alias '@/*'
npm install drizzle-orm @neondatabase/serverless
npm install -D drizzle-kit
```

### Validators
```bash
npm run build
npm run lint
```
