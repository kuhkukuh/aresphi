# Spec: F-014 Design System & Component Library

**Feature ID:** F-014  
**Priority Score:** 24  
**Estimated Time:** 2.5 hours with AI

---

## Summary

Typography system (Playfair Display + Geist fonts), color palette (orange brand + warm neutrals), reusable UI components, Framer Motion animations, and property card with hover glow effect. Based on 4 design references in `docs/design-inpirations/`.

## Component Specs

### Button

```typescript
interface ButtonProps {
  variant?: 'primary' | 'secondary' | 'outline';
  size?: 'sm' | 'md' | 'lg';
  children: React.ReactNode;
}

// Variants:
// - primary: bg-stone-900 text-white
// - secondary: bg-orange-500 text-white
// - outline: border border-stone-900 text-stone-900
```

### PropertyCard

```typescript
interface PropertyCardProps {
  property: {
    id: string;
    title: string;
    price: number;
    city: string;
    images: string[];
    type: 'sale' | 'rent';
  };
}

// Features:
// - Glow effect on hover (radial gradient following mouse)
// - Image with hover zoom
// - Price formatting
// - Badge for sale/rent
```

## Animation Utilities

```typescript
// src/presentation/lib/animations.ts
import { Variants } from 'framer-motion';

export const fadeInUp: Variants = {
  hidden: { opacity: 0, y: 20 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.6, ease: 'easeOut' }
  },
};

export const fadeIn: Variants = {
  hidden: { opacity: 0 },
  visible: { 
    opacity: 1,
    transition: { duration: 0.4 }
  },
};

export const staggerContainer = {
  hidden: { opacity: 0 },
  visible: {
    opacity: 1,
    transition: { staggerChildren: 0.1 }
  }
};
```
