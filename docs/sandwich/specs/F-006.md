# Spec: F-006 Homepage - Company Profile

**Feature ID:** F-006  
**Priority Score:** 15  
**Estimated Time:** 3 hours with AI

---

## Summary

Landing page with hero section, company profile, services preview, property highlights, testimonials, team profiles, and contact CTA. **Primary goal: Build trust and drive WhatsApp inquiries.**

---

## Acceptance Criteria

| ID | Given | When | Then |
|----|-------|------|------|
| AC-001 | User visits the homepage | Page loads | Hero section displays with headline, subheadline, CTA button, and background image |
| AC-002 | Homepage renders | User scrolls past hero | About Us section with company description and USPs is visible |
| AC-003 | Stats section is rendered | Section enters viewport | Numbers animate from 0 to target value |
| AC-004 | Property highlights section exists | Section renders | Up to 6 featured properties display with hover glow |
| AC-005 | Testimonials section exists | User views section | Client testimonials display in carousel/slider |
| AC-006 | Team section is rendered | Section displays | Team cards show photo, name, role, WhatsApp link |
| AC-007 | User is on homepage | FloatingWhatsApp is present | WhatsApp button visible in bottom-right |
| AC-008 | Homepage loads | SEO metadata is requested | Correct title, description, OpenGraph tags |

---

## Scope

### In Scope
- Hero section with background image, headline, CTA
- About Us section with company description
- USP grid (3-4 unique selling points)
- Animated statistics counter
- Featured properties section (static or from CMS)
- Testimonials carousel/slider
- Team profiles section
- Contact CTA section
- WhatsApp integration
- SEO metadata
- FadeInUp scroll animations

### Out of Scope
- Property listing page
- Property detail page
- Admin content management
- Blog section on homepage
- Newsletter signup form
- Live chat widget
