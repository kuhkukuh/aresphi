# F-010: Property Management Admin

> **Module:** Admin · **Priority:** 11/100 · **Depends on:** — · **Source:** prd.md:126-138

Admin dashboard for managing property inventory catalog with CRUD operations. Image upload to Vercel Blob, property status tracking, photo section assignment. Static auth via env variables. Dashboard with tabs for Properties, Stats, Hero photos.

## Scope

**In:**
- CRUD operations for property inventory catalog
- Image upload to Vercel Blob for property photos
- Property status tracking (available, sold, rented)
- Admin selects which photos appear in each section (Hero, Showcase)
- Static authentication via environment variables
- Dashboard tabs: Properties, Stats, Hero photos

**Out:**
- OAuth authentication
- User role management
- Audit logging
