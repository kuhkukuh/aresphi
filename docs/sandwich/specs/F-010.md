# F-010: Property Management Admin

> **Module:** admin · **Priority:** 11/100 · **Depends on:** — · **Source:** prd.md:126-135

Admin dashboard untuk managing property inventory catalog dengan CRUD operations. Image upload to Vercel Blob, property status tracking, photo section assignment. Static auth via env variables.

## Scope

**In:**
- CRUD operations untuk property inventory catalog
- Image upload to Vercel Blob untuk property photos
- Property status (available, sold, rented)
- Admin selects which photos appear in each section (Hero, Showcase)
- Static authentication via environment variables

**Out:**
- OAuth authentication
- User management/multiple users
- Role-based permissions
