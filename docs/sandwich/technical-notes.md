## Architecture Notes
### Admin Dashboard with Static Auth
Admin accesses dashboard using static credentials stored in environment variables. No OAuth or user management system needed. Simple HTTP Basic Auth or custom login comparing against env vars. Session via signed cookies.

### Property Photo Management
Admin uploads property photos to Vercel Blob via admin dashboard. Each property can have multiple photos. Admin designates which photo appears in Hero, Property Showcase, and other sections. Store photo URLs and section assignments in database.

### Stats Management
Stats (properties sold, clients, years, success rate) stored in database and editable via admin dashboard. Allows marketing team to update achievements without code changes. Single row table or key-value config.

### Incremental Static Regeneration for Properties
Use Next.js ISR to cache property listings with revalidation interval. Properties don't change frequently, so 1-hour revalidation is acceptable. Keeps database load low while ensuring fresh data.

### Lead Capture: Mailto + WhatsApp Only
No backend form processing needed. Contact form uses mailto: for email and WhatsApp deep links (wa.me/62xxx) for direct messaging. No lead storage in database. Simplicity over tracking for MVP.

### Bank Partner Logo Assets
Client has 9 bank partners (BNI, BJB, BTN, BRI, BCA, BPR, BPR HIK, BWS/Bank Woori Saudara, Bank Sampoerna). Need to source official logos and apply greyscale filter for visual consistency in the marquee. Consider SVG format for crisp rendering at any size.

### Deferred: Property Detail & Catalog Pages
Property Detail Page and Catalog Page are confirmed requirements but on hold until designs are provided. Build data models and admin CRUD now, add public pages when design is ready.
